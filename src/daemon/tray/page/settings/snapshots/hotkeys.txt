# Hotkeys

## Dictation hotkey
  note: Works anywhere in Windows
  field #1 Hotkey [hotkey] = "Control+Super" (hint "Click, then press your shortcut (Esc cancels)")
  button #2 Reset to Ctrl + Win <Link> (disabled)

## Activation
  (*) #3 Tap to talk -- Press once to start, again to stop
  ( ) #4 Push to talk -- Hold while you speak

## Behaviour
  [x] #5 Suppress the Start menu -- When the hotkey uses the Windows key
  note: Esc discards a dictation
