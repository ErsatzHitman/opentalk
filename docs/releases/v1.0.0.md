# OpenTalk 1.0

The first public release of OpenTalk: voice dictation for Windows in a single ~4 MB executable. Press a hotkey in any
app, speak, press it again, and clean text is pasted where your cursor is.

## Highlights

- **One portable exe.** No installer, no runtime, no web view; ~0% CPU when idle. Windows 10 / 11, x64.
- **Bring your own speech-to-text.** OpenAI, Groq, xAI, Mistral, Gemini, Deepgram, AssemblyAI, Corti, Tinfoil,
  OpenRouter, custom and Azure OpenAI endpoints. Streaming transport for Deepgram, AssemblyAI, OpenAI Realtime and
  Gemini Live, so most of the transcript is ready by the time you stop talking.
- **Clean text, locally.** Deterministic removal of fillers, stutters, loops and transcription glitches, punctuation
  repair, a personal dictionary with fuzzy correction, snippets and spoken line breaks, all in a few milliseconds.
- **AI cleanup and AI rewrite, independently.** Polish every dictation with an AI model, or end one with *"rewrite this
  concisely"* for a shorter version. Both share one model (OpenAI, Anthropic, Gemini, Groq, OpenRouter, Azure, Bedrock,
  Vertex or any OpenAI-compatible endpoint). A failed AI step never blocks the paste: the transcript is used and History
  marks it *STT fallback*.
- **The recording pill.** A liquid-glass pill with a live waveform that follows your voice, a gentle idle ripple
  while you're silent, a glow while transcribing, the icon of the app you're dictating into, and a cancel button that
  pours out of the pill on hover and springs into place.
- **Everything in the tray.** A compact popup for status, History (searchable, with app icons), Dictionary, Snippets
  and every setting, in light or dark mode. It uses Windows 11 Fluent icons.
- **Careful paste.** Clipboard snapshot and restore, excluded from Win + V history, terminal-aware (Ctrl + Shift + V),
  admin-window detection, and Retry with the audio kept in memory after a failed transcription.
- **Private by design.** No telemetry, no account. Audio is never written to disk, and keys are encrypted with Windows
  DPAPI.

## Install

Download `opentalk.exe` below and run it; see the [README](https://github.com/ErsatzHitman/opentalk#install). The
exe is not code-signed, so SmartScreen may warn on the first run (**More info → Run anyway**). Verify the download
with `opentalk.exe.sha256`.

## Known limitations

- Speech-to-text is cloud-only (bring your own key); there is no offline model.
- The pill is excluded from screenshots and screen sharing (its glass needs a clean copy of the screen).
- Pasting into apps running as administrator is blocked by Windows; the text is left on the clipboard instead.
- The Windows benchmark figures in `docs/BENCHMARK.md` predate the latest UI work, and some desktop-only checks are
  still listed as pending in `docs/DEVELOPMENT.md`.
